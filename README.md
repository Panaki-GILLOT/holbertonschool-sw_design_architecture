## 📊 UML Class Diagram

The system includes the following main classes:

- User
- Product
- Cart
- CartItem
- Order
- Payment
- Admin

These classes represent the core features of an e-commerce system:
- User registration and authentication
- Product management
- Shopping cart functionality
- Order processing
- Payment handling
- Admin management

---

## 🔗 Relationships

- A **User** has one Cart and multiple Orders
- A **Cart** contains multiple CartItems
- A **CartItem** is linked to one Product
- An **Order** has one Payment
- An **Admin** manages Products and Orders
